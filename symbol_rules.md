# Pins
* Grid : 100
* Length : 100

# Text
* Alignment : Center for discrete components, Left for integrated circuits
* Enable "allow automatic placement" for both, so that when rotating the component, the text remains horizontal.

## Value
File → Symbol properties → General tab → Value
* Value : VAL**

* Reference designator

# Graphics
* Line width : 10 mil
* For discrete components, draw the symbol in RGB =(0,0,255) (blue) 
* For integrated circuits : 
  * Border color : width=10, default color = RGB=(132,0,0) (dark red)
  * Fill color : default color = RGB(255,255,176) (light yellow)
  * Drawings inside the symbol : black, width=10
